Co mdedit umí

✍️

WYSIWYG editace

Výsledek vidíte přímo při psaní. Žádné přepínání mezi zdrojovým kódem a náhledem.

📁

Soubory i složky

Otevírejte .md, .markdown a .txt soubory. Markdown soubory ve složce najdete v postranním stromu; nechybí drag & drop ani „Otevřít v“.

🗂️

Osnova dokumentu

Postranní panel s nadpisy usnadňuje navigaci v delších dokumentech. Jeho šířku si přizpůsobíte a aplikace si ji zapamatuje.

🔧

Panel nástrojů

Tučné písmo, kurzíva, nadpisy, seznamy, úkoly, tabulky, odkazy, obrázky, bloky kódu – vše na dosah kliknutí.

💾

Sledování změn

Indikátor neuložených změn v titulku okna a ochrana před nechtěným zavřením bez uložení.

📤

Export

Export do HTML a PDF zachovává tabulky, seznamy, bloky kódu, českou diakritiku i diagramy Mermaid.

📊

Diagramy Mermaid

Pište diagram jako blok kódu a sledujte jeho náhled přímo v dokumentu. Vykreslování funguje i bez připojení k internetu.

🕐

Poslední soubory

Přehled naposledy otevřených souborů a automatické otevření posledního dokumentu při startu.

🖥️

Multiplatformní

Nativní desktopová aplikace postavená na Tauri – běží na Linuxu, macOS i Windows.

Technologie

  • Desktop shell Tauri 2
  • Frontend React 18 + TypeScript
  • Editor engine Tiptap 2
  • Markdown pipeline unified / remark / rehype
  • State management Zustand 4
  • Build tool Vite 5
  • Backend Rust

Aktuální vývojová větev

Novější vývoj přidává správu souborů, Undo/Redo, vylepšené seznamy a tabulky, zoom editoru, statistiky dokumentu ve statusbaru a offline nápovědu v češtině i angličtině přes Help → Help / About. Tyto změny nemusí být součástí níže uvedených instalátorů verze 1.1.0. Podrobnosti najdete v dokumentaci repozitáře.

Pro vývojáře

Zkompilovat svépomocí

Potřebujete Node.js 22, Rust 1.94.1 podle souboru rust-toolchain.toml a systémové závislosti uvedené v README.

Zdrojový kód na GitHubu 
git clone https://github.com/MartinDejmal/mdedit.git
cd mdedit
npm ci
npm run tauri build

Hotový instalátor po buildu najdete v src-tauri/target/release/bundle/.
