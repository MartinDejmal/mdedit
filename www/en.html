What mdedit can do

✍️

WYSIWYG editing

See the result as you type. No switching between source code and preview.

📁

Files and folders

Open .md, .markdown and .txt files. Browse Markdown files in the folder sidebar, with support for drag and drop and “Open with”.

🗂️

Document outline

Navigate longer documents using the heading sidebar. Adjust its width and the app remembers your preference.

🔧

Formatting toolbar

Bold, italic, headings, lists, tasks, tables, links, images and code blocks — all a click away.

💾

Change tracking

An unsaved-changes indicator in the window title and protection against accidentally closing without saving.

📤

Export

HTML and PDF export preserves tables, lists, code blocks, Czech diacritics and Mermaid diagrams.

📊

Mermaid diagrams

Write a diagram as a code block and preview it directly in the document. Rendering works offline, too.

🕐

Recent files

Access recently opened files and automatically reopen your last document at startup.

🖥️

Cross-platform

A native desktop app built with Tauri — runs on Linux, macOS and Windows.

Technology

  • Desktop shell Tauri 2
  • Frontend React 18 + TypeScript
  • Editor engine Tiptap 2
  • Markdown pipeline unified / remark / rehype
  • State management Zustand 4
  • Build tool Vite 5
  • Backend Rust

For developers

Build from source

You need Node.js 22, Rust 1.94.1 as specified in rust-toolchain.toml, and the system dependencies listed in the README.

Source code on GitHub 
git clone https://github.com/MartinDejmal/mdedit.git
cd mdedit
npm ci
npm run tauri build

After building, find the installer in src-tauri/target/release/bundle/.
