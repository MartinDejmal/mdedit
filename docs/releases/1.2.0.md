# mdedit 1.2.0

## What's new since 1.1.0

- Manage Markdown files in the folder browser: rename (selected row or F2), move by drag and drop or a destination picker, and permanently delete with confirmation. Right-click menus expose the same actions. Existing destination files are never overwritten.
- Navigate to the parent directory, create subfolders, and start the browser in the active file's directory. New creates an empty Markdown file immediately in the selected folder when Files is open.
- Use the first toolbar button or View → Toggle file browser to show Files. Tools that do not fit in a narrow window move into the » popup.
- Undo and Redo buttons, with history isolated to the current document.
- Display-only editor zoom from 50% to 200%, controlled by the toolbar selector or Ctrl + mouse wheel. Zoom persists across documents during the session and resets to 100% on startup.
- Status-bar statistics: logical editor-text lines, words, Unicode characters, cursor line/column, and the current Markdown size in UTF-8 bytes, including unsaved edits.
- Bundled offline user guides in Czech and English under Help → Help (F1), plus Help → About with application version and license details.
- Czech and English product website pages with a language switch.

## Fixes and editing improvements

- Opening and switching unedited files no longer causes false Modified state or an unnecessary save dialog.
- Successful file-browser switches scroll the new document to its beginning. Cancelling preserves the current document and viewport.
- Moving or renaming the active file preserves unsaved text and updates the path used by Save.
- Convert selected list items to headings without losing their content.
- Create appropriately sized tables from selected lines, tab-separated text or Markdown tables while retaining inline formatting.
- Tab and Shift+Tab indent/outdent the nearest list item consistently across nested list types.

## Downloads

- Windows x64: EXE and MSI installers.
- macOS Intel and Apple Silicon: DMG and application archives.
- Linux x64 and ARM64: AppImage, DEB and RPM packages.

Windows installers are unsigned. macOS packages use ad-hoc signing and are not notarized by Apple. The application is licensed under GNU GPL v3; the previous MIT claims in documentation have been corrected to match the existing LICENSE.

## Česky

Verze 1.2.0 přidává správu souborů a složek ve filebrowseru, Undo/Redo, přizpůsobivou lištu, zoom editoru, statistiky dokumentu a offline nápovědu v češtině i angličtině. Opravuje falešné označení souborů jako změněných a zobrazuje přepnutý soubor od začátku. Zlepšuje práci s nadpisy v seznamech, tabulkami a odsazováním. Nový dokument lze rovnou vytvořit na disku ve vybrané složce. Podrobnosti a omezení popisuje přibalená nápověda.
