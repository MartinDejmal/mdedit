# mdedit 1.1.0 — release snapshot

These notes describe the tagged release, not all later development. For the current development branch see the [English guide](../user-documentation.en.html), [Czech guide](../user-documentation.html) and [README](../../README.md).

## What's new

- Browse Markdown files in a folder sidebar, with lazy loading, refresh, and safe switching between documents with unsaved changes.
- Render Mermaid diagrams directly in the editor and include them in exported documents.
- Resize the outline sidebar and retain its width between sessions.
- Convert selected text into a task list.

## Fixes

- Fixed an editor freeze when opening documents containing Mermaid diagrams.
- Improved PDF export reliability, formatting, tables, lists, code blocks, and Unicode font support.
- Fixed window closing and unsaved-change handling.

## Downloads

- Windows x64: MSI or EXE installer.
- macOS Intel and Apple Silicon: DMG or application archive.
- Linux x64 and ARM64: AppImage, DEB, or RPM.

Windows installers are unsigned. macOS builds use ad-hoc signing and are not notarized by Apple.
