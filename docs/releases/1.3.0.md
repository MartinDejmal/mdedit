# mdedit 1.3.0

## What's new since 1.2.0

- **Independent text and code fonts:** open View → Font Settings… to choose installed font families separately for headings/body text and inline/block code.
- Search the system font list and preview headings, normal, bold and italic text, or sample code before confirming.
- OK saves both choices for all documents and future sessions. Cancel or Escape discards pending choices. Each category has its own default option.
- When the font list is unavailable, enter an installed family name manually. Browser-only previews also support local font access where the browser provides it and permission is granted.
- Font choices affect only the editor display. Markdown content, save state, Undo history, document statistics and HTML/PDF export fonts remain unchanged.
- Expanded Czech and English offline documentation explains selection, persistence, defaults, missing fonts and browser permissions. Updated product website translations remove a duplicated section left by the merge.

Thanks to **@radekvechet** for the font settings contribution in [PR #69](https://github.com/MartinDejmal/mdedit/pull/69).

## Downloads

- Windows x64: EXE and MSI installers.
- macOS Intel and Apple Silicon: DMG and application archives.
- Linux x64 and ARM64: AppImage, DEB and RPM packages.

Use fonts already installed on your operating system; mdedit does not download or bundle your selected fonts. Missing families use the editor's fallback fonts. Windows installers are unsigned; macOS packages use ad-hoc signing without Apple notarization. The application is licensed under GNU GPL v3.
