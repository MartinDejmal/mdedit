Začínáme

mdedit je desktopový WYSIWYG editor Markdownu pro Windows, macOS a Linux. Formátování vidíte přímo při psaní. Soubory zůstávají na vašem disku; aplikace nevyžaduje účet ani cloudovou službu.

Tato příručka popisuje současnou vývojovou větev. Vydaný instalátor může obsahovat starší sadu funkcí. Přesnou verzi své aplikace najdete v Help → About.

Instalátor vyberte pro svůj systém a procesor: Windows x64 (EXE/MSI), macOS Intel či Apple Silicon (DMG), Linux x64 či ARM64 (AppImage/DEB/RPM). AppImage označte jako spustitelný. Nepodepsané Windows a ad-hoc podepsané, nenotarizované macOS balíčky mohou vyvolat upozornění systému; instalujte pouze důvěryhodné vydání.

Windows desktop používá WebView2 Runtime. Samotná nápověda a Mermaid náhledy nepotřebují internet.

Pracovní plocha a nápověda

Horní menu obsahuje File, Edit, View, Help. Pod ním je nástrojová lišta. Úplně vlevo je Toggle file browser; vpravo se při nedostatku místa objeví » / More editor tools se zbývajícími nástroji. Nabídku zavře akce, kliknutí mimo ni nebo Escape.

Vlevo může být panel Files, za ním Outline s nadpisy a potom editor. Outline zapnete přes View, kliknutím na nadpis se přesunete v dokumentu; jeho pravý okraj lze táhnout a šířka se pamatuje. Dole vidíte cestu, stav Saved / Modified a případné upozornění na externí změnu.

Statusbar navíc zobrazuje Lines, Words, Chars a pozici kurzoru Ln / Col (od 1, při výběru jeho aktivní konec). Jde o text editoru bez Markdown značek: každý odstavec, nadpis, položka seznamu a buňka tabulky tvoří logický řádek; ruční zalomení a řádky kódu přidávají další řádky. Zalomení podle šířky okna ani zoom počty nemění. Prázdný dokument má jeden řádek. Slova jsou skupiny písmen a číslic; znaky se počítají jako Unicode code points včetně mezer a zalomení (emoji mimo složené sekvence jako jeden znak).

Vedle Saved / Modified je velikost aktuálního Markdownu v bajtech UTF-8 (B), včetně neuložených změn. Jde o obsah připravený k uložení, nikoli velikost původního souboru na disku: normalizace Markdownu může tyto hodnoty odlišit. Prázdný Markdown má při uložení jeden koncový LF, tedy 1 B. Údaje se aktualizují při psaní, Undo/Redo a přepnutí souboru; pohyb kurzoru soubor nemění.

Help → Help nebo F1 otevře tuto offline nápovědu. Přepínač Čeština / English mění jazyk nápovědy a About, nikoli celé rozhraní editoru. Zavřete ji tlačítkem Close/Zavřít nebo Escape. Otevřený dokument se tím nemění. Po dobu dialogu jsou nativní nabídky File/Edit/View dočasně vypnuté; pro práci s dokumentem nápovědu nejprve zavřete. Zavření hlavního okna nápovědu skryje a případné neuložené změny dál chrání potvrzovací dialog.

Zoom: v rozbalovacím seznamu lišty vyberte 50–200 %, nebo nad editační plochou použijte Ctrl + kolečko (nahoru zvětší, dolů zmenší). Pro zoom se používá Ctrl také na macOS. Nevejde-li se seznam na lištu, je pod ».

Zoom mění pouze zobrazení editoru, nikoli lištu, Files či Outline, obsah Markdownu, stav Saved/Modified, historii Undo ani HTML/PDF export. Zachová se při přepínání i vytváření dokumentů v rámci běhu aplikace; při novém spuštění je vždy 100 %. Neukládá se do nastavení ani do souboru.

Otevření, nový dokument a ukládání

  • File → Open… otevře .md, .markdown nebo .txt. Soubor lze také předat aplikaci jako argument při spuštění, přes „Otevřít v“ nebo přetáhnout z operačního systému na okno aplikace.
  • File → New: při otevřeném Files a vybrané složce se rovnou vytvoří prázdný soubor Untitled.md. Pokud jméno existuje, použije se Untitled 2.md atd. Soubor se otevře jako Saved. Bez vybrané složky nebo při skrytém filebrowseru vznikne pouze nepojmenovaný dokument v editoru.
  • Save uloží současný dokument. U nepojmenovaného dokumentu nejprve vybere cestu; Save As… vybere novou cestu vždy. Aplikace neukládá automaticky každý stisk klávesy.
  • Recent Files nabízí poslední soubory. Při spuštění se bez předaného souboru aplikace pokusí obnovit poslední otevřený dokument.
  • Reload from disk načte aktuální soubor znovu. Když soubor změní jiná aplikace, zobrazí se doporučení reloadu; neuložený text se nepřepisuje automaticky.

Modified znamená změny proti uloženému stavu. Pouhé otevření nebo převod Markdownu do editoru není uživatelská úprava. Undo může vrátit stav na Saved. Historie Undo/Redo se při otevření jiného dokumentu nebo reloadu vynuluje.

Neuložené změny a potvrzovací dialogy

Při přepnutí souboru ve Files se dialog Save changes before switching files? ukáže jen u změněného dokumentu. Save uloží a pokračuje, Discard změny zahodí, Cancel ponechá dokument otevřený. Zrušené Save As nebo chyba zápisu přepnutí zastaví. Po úspěšném přepnutí se editor posune na začátek nového souboru; zrušení přepnutí zachová pozici v aktuálním dokumentu.

Při New, běžném Open, reloadu nebo zavření okna používá aplikace potvrzení Discard unsaved changes? s volbami Discard / Keep Editing. Pokud chcete změny zachovat, zvolte Keep Editing, uložte dokument a akci zopakujte. Křížek okna respektuje tuto ochranu.

Potvrzené smazání otevřeného souboru ve Files je jiné: maže soubor z disku a při neuloženém dokumentu upozorní také na ztrátu jeho změn.

Filebrowser: složky a souborové operace

Files otevřete první ikonou lišty nebo View → Toggle file browser. Je-li otevřen uložený soubor, kořenem se stane jeho složka. Jinak lze vybrat složku přes Open folder / Choose folder. Strom ukazuje podsložky a pouze .md soubory včetně .MD; .markdown a .txt lze otevřít přes File → Open, ale strom je neukazuje. Symbolické odkazy se nezobrazují.

  • Kliknutí na složku ji vybere a rozbalí/sbalí. Kliknutí na kořenový řádek vybere kořen. Vybraná složka je cílem New a New folder.
  • Parent folder posune celý strom o adresář výše; na kořeni disku či sdílení je vypnuté. Refresh folder znovu načte strom.
  • New folder nechá zadat jméno a vytvoří novou složku uvnitř vybrané složky. Existující cíl se nepřepisuje.
  • První klik na soubor ho otevře. Klik na již vybraný řádek nebo F2 otevře přejmenování. Jméno musí končit .md a nesmí obsahovat oddělovače cesty či rezervované znaky.
  • Soubor přesuňte tažením na složku nebo na kořenový řádek. Po přesunu se cílová složka rozbalí. Pokud cíl se stejným názvem existuje, operace skončí chybou a nepřepíše jej.
  • Pravé tlačítko na souboru nabízí Open, Rename…, Move to folder…, Delete…. Move to folder otevře výběr cílové složky. Pravé tlačítko na složce nabízí její otevření jako kořen stromu a New folder.
  • Delete nebo Delete… žádá potvrzení. Smazání je trvalé; aplikace nepoužívá koš. Smazání otevřeného dokumentu po potvrzení otevře prázdný nepojmenovaný dokument.

Přesun a přejmenování otevřeného souboru zachovávají jeho neuložený text, stav Modified a aktualizují cestu pro další Save. Tyto operace pracují se soubory; přejmenování, přesun nebo rekurzivní mazání celých složek nyní nejsou součástí UI.

Formátování, seznamy a tabulky

  • Lišta nabízí tučné písmo, kurzívu, nadpisy, odrážky, číslování, úkoly, tabulky, odkazy, obrázky a bloky kódu. Undo / Redo se aktivují podle dostupné historie.
  • Tlačítko nadpisu cykluje běžný text → H1 → H2 → H3 → běžný text. V položce seznamu nejprve zruší její seznamové obalení; okolní položky a inline formátování zůstanou zachované. Celý převod vrátí jedno Undo.
  • Tab / Shift+Tab v seznamu zvýší/sníží úroveň nejbližší položky, také v úkolových či smíšených seznamech. První položka bez předchozího sourozence nemá kam vnořit: Tab ji nemění a fokus zůstane v editoru. Shift+Tab na vnější úrovni může změnit položku na odstavec.
  • Task list bez výběru vytvoří úkolový seznam; s vybraným víceřádkovým textem převede řádky na úkoly. Checkbox mění stav úkolu.
  • Insert table bez výběru vloží tabulku 3×3 s hlavičkami A/B/C. S výběrem vytvoří řádek pro každý vybraný odstavec či zalomení řádku. Tabulátory oddělují sloupce; běžný Markdown zápis s krajními svislítky je také podporovaný a oddělovací řádek hlavičky se nepřenáší jako data. První řádek slouží jako hlavička, kratší řádky se doplní prázdnými buňkami. Inline formátování i text mimo výběr zůstanou zachované.
  • Insert link nastaví URL vybranému textu, nebo ji vloží do prázdného výběru. Remove link odebere odkaz. Insert image from URL nabídne URL a volitelný alternativní text; správu lokálních příloh aplikace zatím neposkytuje.

Kód a Mermaid

Zapněte Code block a v poli Code vyberte jazyk. Podporované volby zahrnují plaintext, Mermaid, JavaScript, TypeScript, JSON, HTML, CSS, Bash, SQL, YAML a Markdown.

Pro diagram zvolte mermaid. Náhled pod zdrojovým kódem se průběžně aktualizuje; při chybné syntaxi ukáže chybu. Mermaid je přibalený a nevyžaduje CDN. Například zdroj flowchart LR a na dalším řádku A[Začátek] --> B[Konec] vytvoří jednoduchý diagram.

Export HTML a PDF

File → Export as HTML… / Export as PDF… nebo ikony lišty exportují současný obsah editoru včetně neuložených změn. Jméno se odvodí od dokumentu; cílovou cestu potvrdíte v dialogu. Export neoznačí původní Markdown za uložený.

PDF má označitelný text, přibalené patkové/monospace fonty s diakritikou, zvýraznění kódu, seznamy, checkboxy, bloky v tabulkách, obrázky a vektorové Mermaid diagramy. Dlouhý dokument se stránkuje; výstup nemusí mít pixelově totožné zalomení jako šířka editoru.

Vzdálený obrázek musí být dostupný a jeho server musí dovolit CORS pro vložení do PDF. Nedostupný obrázek export zastaví s chybou místo tiché ztráty obsahu. HTML export je samostatný dokument se styly; jeho Mermaid náhled nyní načítá knihovnu z CDN a potřebuje internet. To se liší od offline náhledu v editoru a PDF exportu.

Omezení a řešení potíží

  • Markdown ↔ HTML převod není bezztrátový pro všechny konstrukce. Pro důležité či nestandardní soubory si před editací ponechte kopii; aplikace nepředstavuje správce záloh ani verzování.
  • Když se operace nepovede, zobrazí se toast nebo chyba ve stromu. Zkontrolujte práva, existenci složky, kolizi názvu a dostupnost souboru. Seznam obnovte pomocí Refresh.
  • Pokud byla data změněna zvenčí, nejprve rozhodněte, zda chcete zachovat svůj text, nebo načíst diskovou verzi. Reload může po potvrzení neuložené změny zahodit.
  • Chybějící ikony hledejte pod »; dočasně lze panel Files či Outline skrýt přes View.
  • U chyby Mermaid ověřte syntaxi a zvolený jazyk. U PDF chyby obrázku ověřte URL a CORS. Bez aktivního dokumentu není co exportovat.
  • Nápověda přepíná pouze svůj jazyk. Kompletní lokalizace editoru ani dark mode nejsou nyní zavedené.
